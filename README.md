# shurjoPay v2 ড্যাশবোর্ড (shurjoPay v2 Dashboard)

![Dashboard Banner](./src/assets/images/app_dashboard_banner_1789589067087.jpg)

একটি আধুনিক এবং শক্তিশালী পেমেন্ট ম্যানেজমেন্ট প্ল্যাটফর্ম যা **shurjoPay v2 Gateway** এবং **Gmail Integration** এর সমন্বয়ে তৈরি করা হয়েছে। এই অ্যাপটি ব্যবহারকারীকে পেমেন্ট গ্রহণ, ট্র্যাকিং এবং গ্রাহকদের সাথে যোগাযোগ স্থাপনে সহায়তা করে।

## প্রধান বৈশিষ্ট্যসমূহ (Key Features)

  <img src="./src/assets/images/shurjopay_integration_graphic_1789589080021.jpg" width="150" alt="shurjoPay" />
  <img src="./src/assets/images/gmail_integration_graphic_1789589090431.jpg" width="150" alt="Gmail" />

- **🚀 shurjoPay Gateway Integration:** খুব সহজেই shurjoPay-এর মাধ্যমে পেমেন্ট গ্রহণ এবং যাচাই করার সুবিধা।
- **📧 Gmail Communication Hub:** সরাসরি ড্যাশবোর্ড থেকে জিমেইল মেসেজ দেখা এবং কাস্টম টেমপ্লেট ব্যবহার করে পেমেন্ট রিসিট পাঠানোর সুবিধা।
- **📊 Transaction Analytics:** Recharts-এর মাধ্যমে পেমেন্ট ভলিউম এবং ট্রেন্ডের ভিজ্যুয়াল সামারি।
- **🌙 Global Dark Mode:** চোখের আরামের জন্য উন্নত ডার্ক মোড থিম সাপোর্ট।
- **⚙️ Customizable Layout:** ড্যাশবোর্ডের কার্ডগুলো (Payments, History, Gmail) নিজের ইচ্ছেমতো শো/হাইড করার ব্যবস্থা।
- **📝 Email Templates:** পেমেন্ট রিসিট বা অন্যান্য মেসেজের জন্য কাস্টম টেমপ্লেট সেভ এবং পুনরায় ব্যবহার করার ফিচার।
- **🔔 Real-time Notifications:** টোস্ট নোটিফিকেশন সিস্টেমের মাধ্যমে অ্যাপের প্রতিটি অ্যাকশনের ইনস্ট্যান্ট ফিডব্যাক।

## প্রযুক্তিগত বিবরণ (Tech Stack)

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Backend/Storage:** Firebase (Firestore, Auth)
- **API Integration:** shurjoPay V2 API, Google Gmail API
- **Animations:** Motion (Framer Motion)
- **Utilities:** Recharts, React-Markdown

## কীভাবে ব্যবহার করবেন?

১. **লগইন:** আপনার গুগল অ্যাকাউন্ট ব্যবহার করে নিরাপদভাবে লগইন করুন।
২. **পেমেন্ট:** 'shurjoPay Gateway' কার্ডে গিয়ে নির্দিষ্ট অ্যামাউন্ট দিয়ে পেমেন্ট শুরু করুন।
৩. **সেটিংস:** আপনার পছন্দমতো ডার্ক মোড বা ড্যাশবোর্ড লেআউট পরিবর্তন করতে সেটিংস প্যানেল ব্যবহার করুন।
৪. **জিমেইল:** জিমেইল কানেক্ট করে আপনার গ্রাহকদের কাস্টম ইমেইল টেমপ্লেট দিয়ে দ্রুত যোগাযোগ করুন।
